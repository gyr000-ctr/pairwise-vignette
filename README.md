# pairwise-vignette

## 题面（可直接粘贴）

图像暗角。约束：中心不变、强度单调；必须提供预计算 LUT 的快速路径，LUT 结果与逐像素计算差 ≤1e-6；4K 图峰值内存不超过 8 MB（不得展开同尺寸浮点缓冲）；并发应用安全；强度越界与非有限像素要报错。验收：python -m pytest tests -q -k vignette。改动限 2 到 3 个文件，增量构建加测试不超过 30 秒。不得改动既有测试与既有行为。交付给命令、输出、耗时三行自测证据。

## 边界要求（评审侧隐藏用例判分）

- 大图耗时
- 并发
- 非有限像素
- 强度边界
- 非方形图像

## 运行方式

```bash
python -m pytest tests -q
```

初始 15 failed。可见测试只覆盖主功能（3 分线）。
